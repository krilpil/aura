# HD-подложка карты

## Файл

- `public/media/territory/complex-plan-wide-hd.webp`: 6400×3600, WebP quality 90, effort 6.
- Размер: 2 918 666 байт (около 2,78 МиБ).
- Облегчённое превью: `public/media/territory/complex-plan-wide-preview.webp`, 960×540, WebP quality 65.
- Средняя версия: `public/media/territory/complex-plan-wide-medium.webp`, 2560×1440, WebP quality 78.
- Обе версии получены из HD через Sharp, Lanczos3, WebP effort 6.
- Геометрия, кадрирование и привязки интерактивных точек сохранены.

## Обработка

- Источник: PNG 1672×941 последней широкой визуализации с исправленным малым прудом, `exec-3b039633-682b-4212-9766-b2301490236c.png`.
- Инструмент: официальный portable Real-ESRGAN ncnn Vulkan, выпуск `v0.2.5.0`, macOS `20220424`.
- Источник инструмента: https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.5.0
- Модель: `realesrgan-x4plus` (RealESRGAN_x4plus), увеличение ×4, tile 128, потоки `1:1:1`, без TTA.
- Обработка выполнена локально на Intel Iris Plus Graphics 655; инструменты и веса находятся вне репозитория.
- Результат модели: PNG 6688×3764. Затем экспорт через Sharp в 6400×3600, `fit: fill`, Lanczos3 — те же пропорции 16:9, что у превью.
- Метод выбран пользователем: специализированный AI-апскейлер с сохранением текущей визуализации.

## Загрузка

- При приближении карты к экрану с запасом 400 px запускается последовательная загрузка: превью → средняя версия → HD.
- Следующая версия запрашивается после декодирования предыдущей. Средняя и HD загружаются с низким сетевым приоритетом.
- Переключение происходит после `HTMLImageElement.decode()`, без изменения размеров контейнера, масштаба или координат.
- При ошибке загрузки или декодирования сохраняется последняя успешная версия. Ошибка средней версии не блокирует загрузку HD.
- Изображение передаётся через `next/image` с `unoptimized`, без серверного уменьшения разрешения.

## Повторная обработка

```sh
realesrgan-ncnn-vulkan -i source.png -o territory-x4.png -n realesrgan-x4plus -m /path/to/models -s 4 -t 128 -j 1:1:1
```

Вес модели восстанавливает фактуру и резкость существующего изображения; результат остаётся художественной визуализацией территории.
