# Обновление меню ресторана

Единственный источник меню — `public/media/restaurant/menu/aura-menu.pdf`.
Заменяйте этот файл актуальным PDF с любым количеством страниц.
Блюда и цены в коде сайта не хранятся.

Один раз подготовьте окружение генератора:

```sh
python3 -m venv /tmp/aura-menu-venv
/tmp/aura-menu-venv/bin/pip install -r scripts/requirements-menu.txt
```

После каждой замены PDF выполните одну команду:

```sh
/tmp/aura-menu-venv/bin/python scripts/generate-menu-previews.py
```

Скрипт создаёт WebP-превью всех страниц и список для карусели
`src/screens/RestaurantScreen/model/menu-pages.json`, автоматически удаляя лишние
превью при уменьшении числа страниц. Размеры страниц берутся из PDF.
Список содержит только номера страниц, пути, размеры и версию файла;
редактировать его вручную не нужно. PDF скрипт не изменяет.

Сохраняйте обновлённый PDF, превью и сгенерированный список вместе, затем
пересоберите и опубликуйте сайт обычным способом. Версия в ссылках обновляется
по содержимому PDF, чтобы браузер загружал актуальные файлы.

Кухни, средний чек и режим работы находятся отдельно в
`src/screens/RestaurantScreen/model/menu.ts`.
Python и библиотеки генератора не требуются для запуска и сборки сайта.
